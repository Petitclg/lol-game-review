# Composants tiers

## FFmpeg

Les releases embarquent un build LGPL de [FFmpeg](https://ffmpeg.org/) (via [BtbN/FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds)), exécuté comme processus séparé. FFmpeg est distribué sous licence LGPL v2.1+. Le code source correspondant est disponible auprès du projet FFmpeg et de BtbN.

## Data Dragon
