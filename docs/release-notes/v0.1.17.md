**Nouveautés**
• **Parties accessibles sans le client LoL** : les parties enregistrées s'affichent même quand le client est éteint ou qu'aucun compte n'y est connecté. Lancé, le client ajoute l'historique récent et les résultats.
• **Gestion multi-compte** : les comptes sont détectés dans les enregistrements et un menu dans l'en-tête permet de choisir celui dont on voit les parties (le compte connecté au client par défaut).
• **Parties hors historique** : une partie que le client n'a jamais vue s'affiche avec « Résultat inconnu » au lieu d'une fausse défaite.
